# Скриншоты

Здесь лежат скриншоты UI, на которые ссылается README.md. Пока — плейсхолдеры:
нужен доступ к живому LuCI (делаются на роутере после деплоя релиза).

## Нужные скриншоты (имена файлов зафиксированы в README)

| Файл | Что снять |
|---|---|
| `dashboard.png` | Дашборд: статус туннеля, активная нода, график скорости, переключатель движка |
| `nodes.png` | Пул нод: флаги, пинги, группы, выбор активной |
| `routing.png` | Маршрутизация: правила с действиями (proxy/direct/block/antidpi), пресеты |
| `devices.png` | Устройства: список DHCP-клиентов с per-device маршрутами |

Дополнительно (не обязательно, для docs/):

| Файл | Что снять |
|---|---|
| `fallback.png` | Редактор fallback-цепочки |
| `antidpi.png` | Страница оптимизации доставки: профили стратегий, статус guardian |
| `components.png` | Компоненты: версии бинарей, кнопки обновления |
| `diag.png` | Диагностика: зелёные/красные статусы этапов |

## Как снимать

1. Развёрнутый релиз на роутере, тёмная тема Морока, окно браузера 1440px.
2. Перед съёмкой Ctrl+Shift+R (сброс кэша LuCI).
3. Не допускать в кадр: реальные серверы нод, ключи, HWID, внешние IP —
   замазать или использовать тестовые данные.
4. PNG, без сжатия-мыла; желательно Retina (2x) — README покажет чётко.
