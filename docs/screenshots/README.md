# Скриншоты

Скриншоты UI, на которые ссылаются README.md и лендинг (docs/site/).
Снимаются **без роутера**: настоящие LuCI-вьюхи Морока рендерятся
в оффлайн-стенде с заглушками LuCI-рантайма и ubus
(`tools/screenshots/`: `shim.js` эмулирует `E()`, `L`, `view`, `ui`, `rpc`,
`poll`, `uci`; `mock-data.js` — вымышленные данные; `harness.html` — страница
`?view=<имя>`).

**Все данные на скриншотах вымышленные**: endpoint'ы из документационных
диапазонов RFC 5737 (198.51.100.0/24, 203.0.113.0/24), ссылки подписок —
`*.example.com`. Реальные серверы/ключи/HWID сюда не попадают по постановке.

## Как переснять

```sh
sh tools/screenshots/shoot.sh   # из корня репо
```

Скрипт поднимает временный статик-сервер на свободном порту, снимает каждую
вьюху headless Chrome (1600px, тёмная тема), обрезает пустой фон
(`trim.py`, нужен Pillow) и кладёт PNG сюда. Сервер останавливается сам.

Если вьюха изменилась (новые ubus-вызовы, новые модули в `'require'`) —
дополни `tools/screenshots/mock-data.js` / `shim.js`. Если страница рендерится
пустой — harness пишет стек в `<pre id="morok-shot-error">`, видно на
скриншоте/в `--dump-dom`.

Промежуточные необрезанные кадры лежат в `.raw/` (в git не коммитятся).
